Home-ERP Documentation
======================

Home-ERP is a self-hosted, modular domestic resource planning platform developed with Python and Django. It adapts enterprise-grade architectural patterns for domestic household management, encompassing personal finances, pantry inventory, asset maintenance, and domestic chores.
